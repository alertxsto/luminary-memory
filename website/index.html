v0.1.0 — self-hosted memory layer

What your agent
remembers
is what it becomes.

Luminary-memory gives AI agents a place to keep what matters — across sessions, across tools, on your own infrastructure. Four retrieval strategies, fused into one answer.

get started pip install luminary-memory⧉
recall.py 
from luminary_memory import MemoryClient

client = MemoryClient(db_path="memory.db")

# a fact, stored once
client.ingest("the deploy target is the staging cluster",
              tags=["deploy", "infra"])

# recalled later — semantic, keyword, temporal, graph — one answer
result = client.recall("where do we deploy?")
for m, s in zip(result.memories, result.scores):
    print(f"{s:.3f}  {m.content}")

# → 0.942  the deploy target is the staging cluster

the problem

Every session, your agent
starts over.

A stateless agent re-learns the same context, pays the same tokens, and makes the same mistakes. Memory is not a feature — it is the difference between a tool and a colleague.

01 semantic
Embedding similarity — the meaning behind the words, understood locally on CPU.
02 keyword
FTS5 term matching — exact names, APIs, and identifiers never slip away.
03 temporal
A decay curve over time and access — recent, frequent facts rise first.
04 graph
Entity co-occurrence — the connections between facts, not just the facts.

Four strategies run in parallel. Reciprocal Rank Fusion folds them into a single ranked answer — then dedup and a token budget keep it lean.

RRF k=60 · Jaccard 0.85 · token budget 4096

quickstart

Running in four steps.

  1. 1

    Install

    One package, ONNX CPU embeddings bundled. No GPU, no cloud account.

    pip install luminary-memory ⧉
  2. 2

    Store

    Anything durable — preferences, environment details, decisions.

    client.ingest("the deploy target is staging", tags=["deploy"]) ⧉
  3. 3

    Recall

    Ask naturally. The fused pipeline returns what matters.

    luminary-memory recall "where do we deploy?" --json ⧉
  4. 4

    Maintain

    A lifecycle pass — TTL expiry, consolidation, pruning. The store keeps itself.

    luminary-memory lifecycle ⧉
